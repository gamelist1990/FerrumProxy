# GUIのIP Block設定

インスタンスの「プロキシ設定」→「保護」からIP Blockを設定できます。

- IP Block全体のON/OFF、VPNとデータセンターの遮断を個別に選択できます。
- IPv4・IPv6の個別IPと任意の理由、CIDRネットワークを追加・編集・削除できます。
- リスト設定を開くと、VPN・データセンターの取得URLと更新間隔を変更できます。既定は86,400秒、0は起動時のみです。
- 設定を保存後、インスタンスを再起動して反映してください。IP Blockを無効にしても登録したルールは保持します。

Manager APIを設定した対応プロキシが稼働している場合は、取得済みのVPN・データセンターCIDR数と最終取得からの経過秒数を表示します。「状況を更新」は表示用データの再取得で、公開リストの強制更新ではありません。プロキシ未起動・Manager API未設定・非対応バージョンでも設定の編集と保存はできます。

保存前にGUIバックエンドでIP・CIDR・URL・更新間隔を検証し、不正な設定が稼働用YAMLを置き換えるのを防ぎます。DDoSガードは同じ「保護」タブ内で引き続き設定できます。
